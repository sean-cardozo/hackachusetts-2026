# PharmaPool — Kiro handoff

**Start with `HANDOFF.md`** — it explains the app, the folder and exactly how to build it in Kiro.

Drop the contents of this folder into the root of a new repo, open it in Kiro, then open `.kiro/specs/poolrx/tasks.md` and run tasks in order.

- `BRIEF.md` — one-page product brief (start here)
- `.kiro/steering/product.md` — who it's for, voice, rules Kiro must always follow
- `.kiro/steering/theme.md` — Hackachusetts visual theme (tokens, type, components)
- `.kiro/steering/tech.md` — stack, data feeds, project structure
- `.kiro/specs/poolrx/requirements.md` — user stories + EARS acceptance criteria
- `.kiro/specs/poolrx/design.md` — architecture, data model, sample data, screen specs
- `.kiro/specs/poolrx/tasks.md` — implementation plan
- `reference/PharmaPool.dc.html` — clickable visual reference (open in a browser; match its look)
