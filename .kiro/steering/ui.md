# UI style

Apple-style, clean and calm.

## Colors
- Background: #F5F5F7
- Cards: white
- Text: #1D1D1F
- Secondary text: #6E6E73
- Captions: MIT gray #8A8B8C
- Accent: MIT red #A31F34. This is the ONLY accent. Use it for buttons, active tabs and progress bars only.
- No large red blocks.

## Shapes
- Cards: 20px radius, soft shadow.
- Buttons: pill-shaped, 14px text, the same height everywhere.

## Type
- System font stack (`-apple-system, BlinkMacSystemFont, "SF Pro Text", system-ui, sans-serif`).

## Labels
Every price on screen carries a small caption that says where it comes from: "Benchmark (NADAC)", "Supplier list price", or "Example".

## Access
Make controls keyboard reachable, keep text contrast readable on #F5F5F7, and do not rely on color alone to show status.
